# STEMX365 Assets

Centralized static assets for the STEMX365 platform.

## Directory Structure

- logos/         - STEMX365 logos
- robots/        - Robot images
- simulations/   - Simulation screenshots
- programs/      - Educational programs
- banners/       - Website banners
- icons/         - UI icons
- documentation/ - Technical diagrams

## Accessing Images

Images are accessible through GitHub Raw URLs.

Example:

https://raw.githubusercontent.com/mizanul/stemx365-assets/main/robots/astrobee/astrobee.png

## Usage

Assets can be referenced directly from React, HTML,
and other web applications.
